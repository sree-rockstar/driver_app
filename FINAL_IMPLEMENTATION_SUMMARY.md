## ⚡ Electric Vehicle Features (Complete)

### Simple 5-Field Charging:
**User Enters:**
1. Start SOC (%)
2. End SOC (%)
3. kW Consumed
4. Amount (₹)
5. Charging Station Name

**System Auto-Calculates:**
- SOC Charged = End - Start
- Cost per kWh = Amount ÷ kW
- Duration = End Time - Start Time

## 🚀 How to Run

### Start Backend:
```bash
cd backend
source venv/bin/activate
python create_vehicles_indexes.py  # One-time setup
uvicorn app.main:app --reload --port 8000
```

### Start Frontend:
```bash
cd frontend
npm install  # If not already done
npm run dev
```

### Access:
- **Frontend:** http://localhost:5173
- **API Docs:** http://localhost:8000/docs
- **Admin Dashboard:** http://localhost:5173/admin
- **Admin Fleet:** http://localhost:5173/admin/fleet
