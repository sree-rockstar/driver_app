## ⚡ Quick Start Command

```bash
cd frontend

# Install dependencies
npm install @radix-ui/react-dropdown-menu @radix-ui/react-dialog \
  @radix-ui/react-tabs @radix-ui/react-switch lucide-react \
  class-variance-authority clsx tailwind-merge

# Create directories
mkdir -p src/contexts src/lib src/components/ui

# Start dev server
npm run dev
```
