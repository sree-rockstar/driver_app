🔧 USEFUL COMMANDS
═══════════════════════════════════════════════════════════════════════════════

Deploy:
  ./deploy-azure.sh

View Logs:
  az webapp log tail --resource-group driver-app-rg --name your-app

Restart App:
  az webapp restart --resource-group driver-app-rg --name your-app

Update Code:
  cd backend && zip -r deploy.zip . -x "venv/*" "__pycache__/*" "*.pyc"
  az webapp deployment source config-zip --resource-group driver-app-rg \
    --name your-app --src deploy.zip

SSH Access:
  az webapp ssh --resource-group driver-app-rg --name your-app

🆘 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

App not starting?
  → Check logs: az webapp log tail
  → Verify environment variables
  → Check MongoDB connection

502 Bad Gateway?
  → Database connection timeout
  → Check MongoDB Atlas IP whitelist
  → Add 0.0.0.0/0 to allow all IPs

CORS errors?
  → Update ALLOWED_ORIGINS setting
  → Include your frontend domain
  → Restart app

Module not found?
  → Check requirements.txt
  → Redeploy with: ./deploy-azure.sh

Full troubleshooting: AZURE_DEPLOYMENT_GUIDE.md → Troubleshooting section
